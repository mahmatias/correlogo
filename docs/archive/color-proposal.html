Proposta de Cores — Modo Escuro + Modo Claro com cores adaptadas

Problemas originais: (1) bolinha programada some no fundo do dia selecionado (mesma cor)  ·  (2) barra de progresso do "Finalizar treino" quase invisível  ·  (3) acessibilidade protanopia/deuteranopia
Novidade: cada opção propõe cores de acento diferentes para o modo claro — versões mais escuras/saturadas para manter contraste sobre o fundo branco/creme.

🔑 Lógica de adaptação claro → escuro: No modo claro, o fundo do calendário é branco (#FFFFFF) ou creme (#F0ECE8). As cores de acento precisam ser mais escuras e mais saturadas que no modo escuro para manter o mesmo contraste. A regra geral: lightAccent = darken(darkAccent, 20%) + preservar matiz. O botão "Finalizar treino" (WorkoutTracker) usa bg-accent nos dois modos — não muda porque o fundo do botão é o mesmo rosa nos dois temas.
