Comparativo rápido

  • Opção A — menos cliques, mais scroll. 1 tela, 1 state, mais simples de implementar. Bom para mobile (1 dedo).
  • Opção B — separação clara, mas 4 estados de aba. Bom se cada seção ficar grande. Risco de poluir a tab bar.
  • Opção C — mais telas (1 raiz + N sub-telas), mais cliques. Visual mais "app nativo". Mais código (rotas/sub-nav).
